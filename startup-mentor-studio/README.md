# MentorNote (창업 멘토링 기록)
- 예비·기창업자 구분, 일자, 회차, 아이디어명, 멘토링 메모, 진단, 제안, 실행과제
- 실시간 A4 보고서 / 직접 편집 / Word .docx / PDF 인쇄 / JSON 백업
- 로컬 브라우저 저장 (계정 로그인 및 서버 데이터 저장 없음)
- AI 전문 문장 정리는 Vercel 환경변수 AI_GATEWAY_API_KEY 설정 시에만 활성화
- AI_MODEL을 AI Gateway에서 사용 가능한 모델 ID로 설정 가능
- AI 버튼을 누를 때만 메모가 AI Gateway로 전송됨

Vercel Framework: Other, Root Directory: startup-mentor-studio.
개인정보나 영업비밀은 비식별화하여 입력 권장. 공용 PC 이용 시 기록 삭제. HWP/HWPX 직접 생성은 미지원, .docx 한글에서 열기 가능.
